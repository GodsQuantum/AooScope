# AooScope Animation Pipeline Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add safe HTML/CSS/SVG-authored animation preview and compile localized animation into bandwidth-budgeted partial LCD updates, including an animated orbital AooScope logo.

**Architecture:** Animation definitions are constrained declarative sources stored in the Media Library, previewed in a sandboxed browser frame, rasterized into bounded 960×376 frame sequences, then optimized into changed rectangles. The LCD runtime receives only precompiled assets/rectangles; it never executes HTML or JavaScript.

**Tech Stack:** Python 3.13, Pillow, vanilla HTML/CSS/SVG, headless Chromium only in build/compile tooling where available, `aoostar-rs` partial updates, unittest.

**Spec:** `docs/superpowers/specs/2026-09-12-page-designer-media-animation-design.md`

## Global Constraints

- WTR MAX canvas is 960×376; serial transport is 1,500,000 baud.
- Arbitrary user JavaScript and unrestricted network access are forbidden.
- Full-frame high-FPS video must degrade explicitly instead of saturating the display.
- Animation source never receives provider secrets or filesystem paths.
- Brightness applies to generated frames after composition.
- Core Page Designer plan must be complete first.
